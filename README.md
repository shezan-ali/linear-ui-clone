# Linear-Inspired SaaS Website UI

An independent frontend recreation inspired by Linear's modern website design and visual identity.

## Overview

This project recreates a modern SaaS website experience with a dark visual theme, clean typography, structured layouts, and product-focused content.

## Project Status

Completed — Portfolio practice project.

## Built With

- HTML5
- CSS3
- Google Fonts

## Features

- Dark visual theme
- Structured navigation
- Hero section
- Product-focused content
- Customer and brand presentation
- Carefully styled typography and layouts
